# Data Model: Stock Intelligence Dashboard

This document defines the key entities and data structures used in the Stock Intelligence Dashboard.

## Entities

### StockRecord
Represents a single point in the time-series historical data.

| Field | Type | Description | Validation |
|-------|------|-------------|------------|
| timestamp | DateTime | Date of the record | Must be a valid ISO8601 date |
| open | Float | Opening price | Must be > 0 |
| high | Float | Highest price of the day | Must be >= open, close, low |
| low | Float | Lowest price of the day | Must be <= open, close, high |
| close | Float | Closing price | Must be > 0 |
| volume | Integer | Number of shares traded | Must be >= 0 |
| ma7 | Float | 7-day Moving Average | Calculated field |
| ma21 | Float | 21-day Moving Average | Calculated field |

### CompanyProfile
Fundamental information about the stock ticker.

| Field | Type | Description |
|-------|------|-------------|
| ticker | String | Stock symbol (e.g., AAPL) |
| name | String | Full company name |
| sector | String | Industry sector |
| market_cap | Float | Market capitalization |
| high_52w | Float | 52-week high price |
| low_52w | Float | 52-week low price |

### PredictionOutcome
The output generated by the machine learning model.

| Field | Type | Description |
|-------|------|-------------|
| model_type | Enum | `linear_regression` or `random_forest` |
| predicted_price | Float | Next-day closing price prediction |
| trend | Enum | `increase` or `decrease` |
| current_price | Float | Last known closing price |
| confidence | Float | Optional error metric (e.g., R-squared or MAE) |

## Relationships

- A **Ticker** has many **StockRecords** (Time-series).
- A **Ticker** has one **CompanyProfile**.
- A **PredictionOutcome** is derived from a collection of **StockRecords** for a specific **Ticker**.

## State Transitions

1. **INITIAL**: User enters ticker.
2. **FETCHING**: System calls yfinance API.
3. **PROCESSING**: Data is cleaned and MAs are calculated.
4. **TRAINING**: ML model is trained on processed data.
5. **READY**: UI displays charts, metadata, and predictions.
6. **ERROR**: Displayed if ticker is invalid or API fails.
