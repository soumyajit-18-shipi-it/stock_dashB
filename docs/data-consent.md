# Data Consent

## Current State

The repository's Indic sample dataset is project-authored and does not contain real user submissions.

## Future Collection Rules

Before adding user-contributed feedback or query data:

1. Explain what will be collected.
2. Explain why it is collected.
3. Explain whether it may be used for model training/evaluation.
4. Provide opt-out and deletion instructions.
5. Do not collect sensitive personal data.
6. Record `source`, `license`, and `consent_status` for each row.

## Required Consent Text

Use a short consent statement such as:

> I agree that my anonymized finance query may be used to improve and evaluate Stock Intelligence Dashboard language support. I will not include personal financial account data or identifiers.
